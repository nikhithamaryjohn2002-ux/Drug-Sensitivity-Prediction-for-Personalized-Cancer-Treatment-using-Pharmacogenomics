# Drug Sensitivity Prediction Frontend

Description:  
This repository contains the frontend code for a project predicting drug response in cancer patients using pharmacogenomic data. The frontend provides a user interface to interact with the model and visualize results.

Technologies:  
HTML, CSS, JavaScript 

How to Run:  
1. Clone the repository: `git clone https://github.com/yourusername/DrugSensitivity-Frontend`  
2. Open `index.html` (or main file) in a browser.

Note:  
This is the frontend implementation only. Backend and model integration can be added later.
